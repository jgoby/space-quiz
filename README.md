# Space Quiz

A standalone space exploration quiz with 10 questions, live score and progress tracking, colorful answer feedback, and a results screen. The responsive interface supports light and dark system themes.

## Run

Open `index.html` in a modern web browser. No server, build step, or dependencies are required.

## Live site

The quiz is published at [https://jgoby.github.io/space-quiz/](https://jgoby.github.io/space-quiz/). Pushes to `main` deploy automatically through GitHub Actions.

## Play

Choose an answer and select **Check answer** to see feedback. Use the arrow keys to move between answer choices. Complete all 10 questions to see your results, then select **Play again** to restart.
